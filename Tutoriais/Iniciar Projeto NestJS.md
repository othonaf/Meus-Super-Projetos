# Comando para criar o Projeto:

```bash
nest new nome-do-projeto
```

## Comando para rodar o projeto:

```bash
npm run start:dev
```
## Comando para criar um novo serviço:

```bash
nest generate controller <nome>
```

## Depois de criar um controller, é necessárioi também criar o módulo:

```bash
nest generate module <nome>
```

## Depois de criar um módulo, é necessárioi também criar o 'service'':

```bash
nest generate service <nome>
```
